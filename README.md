# Unity Obstacle Game

## About the Project

A 3D obstacle-course game developed using **Unity and C#**, focused on player movement, obstacle avoidance, collision detection, and gameplay mechanics.

## Features

- **Player Movement:** Control the player while navigating the level.
- **Obstacle Avoidance:** Navigate around obstacles to progress through the game.
- **Collision Detection:** Detect interactions between the player and obstacles.
- **Gameplay Logic:** Implement game behavior using C# scripts.

## Technologies Used

- Unity
- C#
- Unity Physics and Colliders
- Git and GitHub
